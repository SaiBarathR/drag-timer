# Keys and clicks

There are not many. A menu-bar app has no menus to list its keys in, so these are the keys and clicks that are Drag
Timer's own, in one place. The same list is the last page of the Welcome Guide in the app.

Copy, Paste and the rest of the Edit menu's shortcuts work in every text field, as they do in any app.

## The clock

| Click | What it does |
| --- | --- |
| Click | Open the panel, or shut it |
| Drag | Pull out a timer |
| Right-click | History, Settings, the Welcome Guide and Quit |

## While dragging

| Key | What it does |
| --- | --- |
| <kbd>Esc</kbd> | Let go of the drag: no timer starts |

Bringing the pointer back onto the clock, where the label reads **Cancel**, and letting go does the same.

## Naming a timer

| Key | What it does |
| --- | --- |
| <kbd>Return</kbd> | Save the name |
| <kbd>Shift</kbd> <kbd>Return</kbd> | Add a line to the name |
| <kbd>Esc</kbd> | Keep the timer, under the name it has |

## In the panel

| Key | What it does |
| --- | --- |
| <kbd>Return</kbd> | Mark a finished timer done |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo Stop all, or a timer cancelled or finished early |

<kbd>⌘</kbd> <kbd>Z</kbd> undoes for ten seconds after the stop. While a length is being typed or Timer details is
open, it undoes the text instead.

## Typing a length

| Key | What it does |
| --- | --- |
| <kbd>Return</kbd> | Start the length or time typed |
| <kbd>Esc</kbd> | Put the field away |

## The Welcome Guide

| Key | What it does |
| --- | --- |
| <kbd>→</kbd> <kbd>←</kbd> | Turn its pages |
| <kbd>Return</kbd> | The next page, or Get Started on the last |
| <kbd>Esc</kbd> | Shut it |
