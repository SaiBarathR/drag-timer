# Drag Timer 1.6.0 release checklist

## Release scope

| Item | Result | Evidence |
| --- | --- | --- |
| Drag feel unchanged from 1.5 | Pass | `DragFeelLockTests` passed unchanged through PRs #38 to #44. The drag gained a cancel zone on the icon and an Escape key (PR #41); the ruler, detents, snapping and release path were not touched. Ordinary, cancelled and Escaped drags were made on the release binary with real pointer events |
| Finished timer stays in the menu bar | Pass | PRs #38 and #44. Exercised in the running app in all four menu-bar modes, with one and with two finished timers, across a minute boundary, and for a timer already 30 and 61 minutes overdue at launch |
| System sounds and spoken name | Pass | PRs #39 and #44. The app's audio output was measured through Core Audio for a one-shot, a looping sound, the system beep, and two and three timers ending close together |
| Seconds and times of day | Pass | PR #40. Typed `45s`, `1m30`, a time of day (fired within a second after the minute, never before) and a 45-second preset in the running app |
| Time left on a running timer | Pass | PR #43. Add and Subtract 1 min, a typed Time left, an untouched field saved after another timer finished behind the sheet, and the sheet closing when its timer rings |
| Undo | Pass | PRs #42 and #44. Stop all, Cancel and Mark done undone in the running app, including a paused timer, a pinned timer, Command-Z, the offer lapsing after ten seconds, and one timer restarted from History while the rest stayed on offer |
| Per-feature review | Pass | Each of PRs #38 to #43 reviewed by Grok 4.7 (high) in two or three passes; 28 findings, 25 fixed and 3 skipped with reasons recorded on the pull requests |
| Pre-release review | Pass | Everything since `v1.5.0` reviewed as one diff by gpt-6.1 sol, Grok 4.7 and Opus 5.5; 11 distinct findings, 7 fixed and 4 skipped with reasons in PR #44. Grok then reviewed that pull request over several passes; the further findings and what was done with each are listed on it |
| Version classification | Pass | New user-visible features, so the release advances from 1.5.0 to 1.6.0 |
| Release notes | Pass | `docs/releases/v1.6.0.md` |

## Runtime checks

Unless a row says otherwise, these were run on the universal release executable taken from the candidate bundle and started outside it, with its own home directory and its own preferences, so that nothing was shared with the installed copy. Run that way the executable has no notification centre.

| Check | Result | Evidence |
| --- | --- | --- |
| Packaged 1.6.0 candidate launches and fires a timer | Pass | The extracted candidate bundle, run with an isolated home and a seeded 12-second timer, fired it 23 ms after it was due, showed "Launch check finished just now" in the menu bar and kept running |
| Finished state, card and Mark done | Pass | A timer already 30 minutes overdue at launch read "Slept finished 30 min ago" in the menu bar and on the card. Answering it returned the menu bar to the running countdown. A second timer then rang and read "Tea finished just now". Two timers finishing 45 seconds apart read "Plank finished just now, and 1 more finished" and "Just now · 1 of 2" |
| Sound and spoken name | Pass | The executable's audio output began when the timer rang and ended when it was answered. The lengths of a sound with its name, of a looping alarm, of the system beep and of queued alerts were measured on debug builds of the same source (PRs #39 and #44) |
| Presets saved by 1.5.0 beside new ones | Pass | A preset stored without the spoken-name field loaded next to a 45-second one that has it ("Start a 5-minute timer", "Start Plank, 45-second timer") |
| Typed length, time of day and short preset | Pass | `1m30` read "Start 1m 30s" and was saved as 90 s; a time six minutes ahead read "Ring at 12:41 PM" and was saved as 311 s; the Plank preset started a 45-second timer |
| Add and Subtract 1 min, Time left | Pass | 310 s left became 247 s after one Add and two Subtracts with the planned length still 311 s; typing `20m` gave 1199 s left and a planned length of 1200 s |
| Stop all, Undo, Command-Z | Pass | "Stopped 3 timers" with the popover still open and the timer file empty, all three back with the same time left after Undo, and a cancelled timer back after Command-Z |
| Cancelling a drag | Pass | Out and back onto the icon: no timer and no popover. Escape while held: no timer. Ordinary drags of 100 and 300 points: 5-minute and 15-minute timers, as in 1.5 |
| Finished-timer banner and notification actions | Not rerun | Nothing in this release changes how a banner is scheduled or answered, except that an undone timer that is already due no longer schedules one. Last observed on the packaged build of 2026-10-06 |

## Publication gate

The annotated `v1.6.0` tag may be pushed only after this checklist, release notes, version bump, and documentation are committed on `main`. The tag-triggered GitHub Actions workflow must independently repeat the build, tests, universal packaging, signature verification, clean extraction, and checksum gates before it publishes the GitHub release.
