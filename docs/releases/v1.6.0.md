# Drag Timer 1.6.0

## Highlights

Drag Timer 1.6.0 leaves the drag ruler exactly as it was and works on the two ends of a timer's life. A finished timer now stays in the menu bar until you answer it, so a missed sound is no longer a missed timer. Timers can be shorter than a minute, can be set to ring at a time of day, and can be retimed while they run. A drag can be cancelled, and Stop all can be undone.

## When a timer finishes

- Until a finished timer is snoozed, restarted or marked done, the menu-bar icon is solid red and counts up from the moment the timer was due (`+2:15`). This comes ahead of any running countdown. Ring mode shows a full red ring. Count mode shows the red icon beside its number, or alone when no timer is running and the zero is hidden.
- The card in the popover says how long ago the timer finished. A timer the Mac slept through counts from when it was due, not from when the Mac woke.
- The Sound menu lists 14 macOS system sounds as well as the system beep. A sound plays once when you pick it.
- **Say the timer's name** speaks "Tea finished" after the sound. It is a per-timer option with a default in Preferences, and is off unless you turn it on. A looping alert starts repeating once the name has been said.
- **Fixed:** a timer that finished while another alert was still sounding made no sound at all. Each one now rings in turn, and timers that end together each say their name when asked to.
- With several finished timers waiting, the one that has been due longest is shown first, also after a sleep.
- A looping sound shorter than about a second repeats as an alarm instead of running together.

## Starting and changing timers

- Typed lengths can carry seconds: `45s`, `90 sec`, `1m 30s`. Presets and routine timers accept the same and are no longer limited to a minute or more.
- **Other length or time…** also reads a time of day after `@`, `at` or `until`: `@3:30pm`, `at 15:30`, `until 4`. A time from 1 to 12 with no am or pm means the next time the clock reads it. The button names the time it will ring, and says so when that is tomorrow.
- A timer's `…` menu has **Add 1 min** and **Subtract 1 min** beside the existing Add at the snooze length.
- **Edit timer** has a **Time left** field. Changing it gives the timer that long from now, and that becomes its planned length. A paused timer stays paused with the new time left. Timer details closes by itself if its timer rings while it is open.

## Backing out

- Bring the pointer back onto the menu-bar icon during a drag, where the label reads **Cancel**, and let go: no timer starts. Before, this started a one-minute timer.
- Escape cancels a drag while the button is still held.
- For ten seconds after **Stop all**, **Cancel timer** or **Mark done** on a running timer, the popover offers **Undo**. Command-Z does the same, except while you are typing a length or have Timer details open, where it undoes the text. The timers come back with the end times they had, paused ones still paused, and a pinned timer keeps its pin. A timer whose end has passed in the meantime finishes and rings at once. Stop all no longer closes the popover.

## Upgrade behavior

- Existing timers, presets, routines, history, expiry cards and settings remain compatible. Stored timers, presets and routine timers gained an optional field for the spoken name; anything saved by 1.5.0 loads with it off.
- If you go back to 1.5.0 after choosing one of the new sounds, that timer or preset rings with Glass there.
- The drag ruler, detents, snap points and release behaviour are unchanged from 1.5.
- A typed length with no seconds part is still rounded to whole minutes, and `1:30` still means an hour and a half.

## Compatibility

- Requires macOS 14 or newer.
- Apple Silicon runtime is verified.
- The universal app contains native `arm64` and `x86_64` slices. Physical Intel runtime testing remains unavailable, so Intel support is provisional rather than claimed as verified.

## Installation

1. Download `Drag-Timer-1.6.0-macos-universal.zip` and `SHA256SUMS.txt`.
2. Keep both files in the same directory and run `shasum -a 256 -c SHA256SUMS.txt`.
3. Unzip the archive and replace the existing `Drag Timer.app` in Applications.
4. Control-click the app, choose **Open**, and confirm. You can also use **Open Anyway** in System Settings > Privacy & Security.

Drag Timer is ad-hoc signed rather than Developer ID signed or notarized, so macOS requires this one-time Gatekeeper confirmation.

## Verification

After extraction, verify the universal executable, signature, and version:

```sh
lipo -archs "Drag Timer.app/Contents/MacOS/DragTimer"
codesign --verify --deep --strict --verbose=2 "Drag Timer.app"
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "Drag Timer.app/Contents/Info.plist"
```

The commands should report both `arm64` and `x86_64`, a valid ad-hoc signature, and version `1.6.0`.
