# Drag Timer 1.7.0

## Highlights

Drag Timer 1.7.0 opens with a guide the first time it is run. A menu-bar app shows a new user one small clock, and nothing on screen gave away that the clock can be dragged, that Escape lets go of a drag, that a typed length can be a time of day, or that Stop all can be undone. It was all in the README. The guide says what the app is for, where each thing is, and which keys it answers. Nothing about the drag, the timers or their sounds has changed.

## A guide, the first time you open it

Seven pages, in a window of its own:

| Page | What it covers |
| --- | --- |
| Pull Out a Timer | the drag, the ruler's steps, the label and **Cancel**, the name prompt |
| Quick Start | clicking the clock, the presets, typed lengths and times of day, routines |
| Running Timers | finishing early, pausing, the `…` menu, **Stop all** and **Undo** |
| When a Timer Ends | the red clock, **Snooze**, **Restart** and **Mark done**, silencing, the notification |
| In the Menu Bar | Deadline, Count, Pinned and Ring, the last-minute warning, the right-click menu |
| Make It Yours | presets and routines, General, Feel, History |
| Keys and Clicks | every key and kind of click that is Drag Timer's own |

Each of the first six has a picture of that part of the app, drawn small, with a numbered dot on each thing worth knowing; a map of the screen with the part lit, and where it is in words; and a card for every number. The seventh is a table.

- **It opens by itself once.** Shutting it is enough; there is no box to tick. After that it is **Welcome Guide** on the menu-bar icon's right-click menu and under **More** at the bottom of the popover, and its footer says so.
- **On a first launch, shutting it opens the popover**, which shows where in the menu bar the clock is. A first launch used to open the popover straight away.
- **The app goes on working behind it.** It is an ordinary window, so a timer can be dragged out with the page about the drag still open.
- **Keys:** `Return` and `→` turn the page, `←` turns back, and `Esc` shuts it from any page.
- Asked for while it is already open, it comes forward at the page it is on. Opened again after it was shut, it starts at its first page.
- It is 900 by 620 points, or as tall as the screen has room for. On a screen too short for it the page scrolls and its buttons stay in view.

## Upgrade behavior

- **You will see the guide once after updating.** Everything in it is news to someone who never had one. Shutting it does nothing else: the popover follows it only on a first launch.
- Settings gained one optional value, whether the guide has been shown. Timers, presets, routines, history, expiry cards and settings from 1.6.1 load as they are.
- Going back to 1.6.1 needs nothing. 1.6.1 does not keep the new value when it saves its settings, so returning to 1.7.0 afterwards shows the guide once more.
- The right-click menu gained **Welcome Guide** between **Settings…** and **Quit Drag Timer**, and the popover's More menu gained it above **Quit Drag Timer**.
- The drag ruler, detents, snap points and release behaviour are unchanged.

## Limits

- The guide opens by itself only once. Shut before it was read, it is on the two menus.
- Its pictures are drawings of the app, not photographs of it, and show sample timers that are not yours.
- Its window cannot be resized, and moves by its top edge like any other.
- It is in English, as the rest of the app is.

## Compatibility

- Requires macOS 14 or newer.
- Apple Silicon runtime is verified.
- The universal app contains native `arm64` and `x86_64` slices. Physical Intel runtime testing remains unavailable, so Intel support is provisional rather than claimed as verified.

## Installation

1. Download `Drag-Timer-1.7.0-macos-universal.zip` and `SHA256SUMS.txt`.
2. Keep both files in the same directory and run `shasum -a 256 -c SHA256SUMS.txt`.
3. Unzip the archive and replace the existing `Drag Timer.app` in Applications.
4. Control-click the app, choose **Open**, and confirm. You can also use **Open Anyway** in System Settings > Privacy & Security.

Drag Timer is ad-hoc signed rather than Developer ID signed or notarized, so macOS requires this one-time Gatekeeper confirmation.

## Verification

After extraction, verify the universal executable, signature, and version:

```sh
lipo -archs "Drag Timer.app/Contents/MacOS/DragTimer"
codesign --verify --deep --strict --verbose=2 "Drag Timer.app"
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "Drag Timer.app/Contents/Info.plist"
```

The commands should report both `arm64` and `x86_64`, a valid ad-hoc signature, and version `1.7.0`.
