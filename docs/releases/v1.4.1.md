# Drag Timer 1.4.1

## Highlights

Drag Timer 1.4.1 restores the menu-bar drag gesture on macOS 27. On that release, pressing and holding the menu-bar icon opened the timer popover instead of showing the drag preview or creating a timer. Clicking still opens the popover; dragging again starts a timer.

## Changes

- Treat a forwarded status-item click that arrives while the mouse button is still held as an in-progress press, not a completed click.
- Sample pointer position and button state until physical release, then start a drag or open the popover.
- Keep the existing 8-point activation threshold, so small jitter does not turn a click into a drag.
- Keep a drag active even if the pointer returns to the origin before release.
- Add deterministic self-check coverage for held clicks, jitter, origin-returning drags, fast releases, and duplicate-release suppression.

## Compatibility

- Requires macOS 14 or newer.
- Apple Silicon runtime is verified, including the macOS 27 drag regression.
- The universal app contains native `arm64` and `x86_64` slices. Physical Intel runtime testing remains unavailable, so Intel support is provisional rather than claimed as verified.
- This update changes status-item input handling only; persisted timers, presets, routines, settings, expiry, and history formats are unchanged from v1.4.0.

## Installation

1. Download `Drag-Timer-1.4.1-macos-universal.zip` and `SHA256SUMS.txt`.
2. Keep both files in the same directory and run `shasum -a 256 -c SHA256SUMS.txt`.
3. Unzip the archive and replace the existing `Drag Timer.app` in Applications.
4. Control-click the app, choose **Open**, and confirm. You can also use **Open Anyway** in System Settings > Privacy & Security.

Drag Timer is ad-hoc signed rather than Developer ID signed or notarized, so macOS requires this one-time Gatekeeper confirmation.

## Verification

After extraction, verify the universal executable, signature, and version:

```sh
lipo -archs "Drag Timer.app/Contents/MacOS/DragTimer"
codesign --verify --deep --strict --verbose=2 "Drag Timer.app"
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "Drag Timer.app/Contents/Info.plist"
```

The commands should report both `arm64` and `x86_64`, a valid ad-hoc signature, and version `1.4.1`.
