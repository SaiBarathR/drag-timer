# Drag Timer 1.4.0

## Highlights

Drag Timer 1.4.0 makes its defining interaction feel deliberate and dependable. The drag gesture now behaves like a physical timer dial: duration steps occupy stable positions, the ruler and haptic feedback agree, and the default release modes start exactly the value shown on screen. The visual overlay also works correctly across built-in and external displays.

## A fixed, tactile duration ruler

- Move through a deliberate duration ladder: every minute through 15 minutes, every 5 minutes through 1 hour, every 15 minutes through 4 hours, and every 30 minutes beyond that.
- Keep familiar durations at fixed physical positions. Changing the maximum duration or feel preset no longer moves 5 minutes, 15 minutes, or 1 hour to a different drag distance.
- Start a barely activated drag at 1 minute instead of accidentally jumping to 2 minutes.
- Align the ruler marks with the values felt through the trackpad: each duration rung has a detent and useful snap points receive stronger feedback.
- Hold a snap without visual or haptic flicker when the pointer jitters near its boundary.

## Predictable release behavior

- **Precise** and **Snappy** now start exactly the duration visible when the pointer is released—there is no hidden momentum after mouse-up.
- **Throwable** remains the explicit momentum-driven option for users who enjoy throwing the timer outward.
- Throwable momentum fades smoothly when the pointer pauses, preventing a stale movement sample from unexpectedly extending a stable preview.
- High-refresh trackpads use time-corrected velocity smoothing for consistent behavior at different event rates.

## Reliable multi-display overlays

- Show the drag line, endpoint, snap feedback, and live duration preview on both built-in and external displays.
- Work regardless of which display macOS considers primary.
- Keep the overlay visible while dragging across display boundaries.
- Give each display its own overlay surface and backing scale for mixed Retina and non-Retina configurations.
- Show the duration label only on the display containing the pointer, avoiding duplicate labels clamped to other screen edges.
- Rebuild the per-display overlay set at the beginning of each drag so reconnecting or rearranging monitors does not leave stale windows.

## Upgrade behavior

- Existing timers, presets, routines, history, expiry cards, notification preferences, and appearance settings remain compatible.
- Stored non-custom feel presets are migrated to the new deterministic mapping automatically.
- Custom feel settings are preserved where possible while adopting the fixed ruler geometry.

## Compatibility

- Requires macOS 14 or newer.
- Apple Silicon runtime is verified.
- The universal app contains native `arm64` and `x86_64` slices. Physical Intel runtime testing remains unavailable, so Intel support is provisional rather than claimed as verified.

## Installation

1. Download `Drag-Timer-1.4.0-macos-universal.zip` and `SHA256SUMS.txt`.
2. Keep both files in the same directory and run `shasum -a 256 -c SHA256SUMS.txt`.
3. Unzip the archive and replace the existing `Drag Timer.app` in Applications.
4. Control-click the app, choose **Open**, and confirm. You can also use **Open Anyway** in System Settings > Privacy & Security.

Drag Timer is ad-hoc signed rather than Developer ID signed or notarized, so macOS requires this one-time Gatekeeper confirmation.

## Verification

After extraction, verify the universal executable, signature, and version:

```sh
lipo -archs "Drag Timer.app/Contents/MacOS/DragTimer"
codesign --verify --deep --strict --verbose=2 "Drag Timer.app"
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "Drag Timer.app/Contents/Info.plist"
```

The commands should report both `arm64` and `x86_64`, a valid ad-hoc signature, and version `1.4.0`.
